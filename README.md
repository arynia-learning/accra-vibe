# Accra Life Beta

A mobile-first browser game frontend connected to the Accra Life Supabase backend.

## Included
- Auth/account creation
- Accra world screen with zone movement
- Player profiles and levels
- Virtual GH₵ wallet + transaction history
- Jobs + server-side salary claims
- Property and car purchases
- Furniture inventory
- Player directory + transfers
- Mobile bottom navigation

## Deploy
Upload the contents of this folder to any static HTTPS host. For a custom domain, point the domain to that host.

Supabase uses only the browser-safe publishable key in `config.js`. Never add a service-role/secret key.
